# AGENTS.md

SvelteKit 2 (Svelte 5, runes) app in plain JavaScript. Hosted as a standalone Node server via Docker on a Synology NAS.

## Commands

- `npm run dev` — dev server
- `npm run build` — production build to `build/` via `@sveltejs/adapter-node`
- `npm run preview` — serve the built app locally
- `npm run lint` — `prettier --check . && eslint .` (checks **all** files, including `.md`/`.yml`; run `npm run format` first)
- `npm run format` — `prettier --write .`

No tests and no typecheck script exist. Verification = `npm run format` then `npm run lint`, plus `npm run build`.

## Non-obvious config

- **Adapter is configured in `vite.config.js`**, passed as an option to the `sveltekit()` plugin (`sveltekit({ adapter: adapter() })`). `svelte.config.js` only sets the preprocessor — do not look for the adapter there.
- **Runes mode is forced** via `compilerOptions.runes` in `vite.config.js` (all non-`node_modules` files). Write new components with runes syntax (`$state`, `$props`, etc.), not legacy Svelte 4 APIs.
- Prettier uses **tabs, single quotes, no trailing commas, width 100** — don't fight it, run `npm run format`.
- Plain JS, no TypeScript (`jsconfig.json`, `checkJs: false`). The `$lib` alias is available.
- Node is pinned to 24 in `.nvmrc` (and `node:24-alpine` in the Dockerfile).

## Generated code

`.svelte-kit/` is gitignored build output, regenerated by `svelte-kit sync` (the `prepare` script). Never edit it or commit it.

## Deployment

- Production build is a Node server (`build/`) served on port 3000 via `Dockerfile` (multi-stage) + `docker-compose.yml`.
- The user builds/deploys **manually on their Synology NAS** (`git pull`, then `docker compose up -d --build` — or Container Manager GUI). Full steps in README.md; keep them in sync if the Docker setup changes.
- `@sveltejs/adapter-auto` is an unused leftover devDependency; the active adapter is `adapter-node`.

## Routes

Much of `src/routes/` is default starter-template demo content (`sverdle/` game, `Counter.svelte`, `Header.svelte`, `about/`). `+page.js`/`about/+page.js` set `prerender = true`.
